# Configuration API

`config.py` defines environment parsing helpers and constants used by the Streamlit UI, analysis modes, protocol classification, visualization behavior, paths, and logging.

::: config
    options:
      members: true
      show_root_heading: false
      show_source: false
      separate_signature: true
      signature_crossrefs: true
      members_order: source
      filters:
        - "!^_"
